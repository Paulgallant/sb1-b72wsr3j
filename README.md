# Streets of Home - Newcastle

A thrilling racing game set in the streets of Newcastle, featuring:

- Dynamic weather system
- Upgradeable vehicles
- Demo version with special features
- In-game currency (Geordie Notes)
- Real Newcastle landmarks

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## Features

- 3D racing with realistic physics
- Weather effects including rain and clouds
- Day/night cycle
- Vehicle upgrades system
- Demo-specific bonuses and achievements
- Newcastle-inspired landmarks including:
  - Tyne Bridge
  - St. James' Park
  - Grey Street buildings
  - Millennium Bridge
  - Quayside

## Demo Version

The demo version includes:
- Limited-time gameplay
- Special demo-only upgrades
- Basic vehicle customization
- Exclusive demo bonuses
